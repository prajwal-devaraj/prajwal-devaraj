### Genetic Variant Conflict Prediction

Machine-learning research project focused on predicting conflicting genetic variant classifications from ClinVar data.

This project required more than training a classifier.

### Results

- Built 20+ engineered features
- Achieved approximately 93.3% accuracy
- Improved F1 score by 18%
- Reduced false-positive predictions by 22%
- Compared ensemble learning approaches
- Used SHAP for model explainability
